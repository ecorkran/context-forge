Context Forge / cf

Use CF directly to understand or update a project’s workflow state.

Set up a project

cd /path/to/project
cf init
cf status

cf init registers the current directory and sets up project guides and IDE integration. For VS Code Copilot, use cf init --ide copilot. sq setup can install CF if needed.

Daily orientation and browsing

cf status
cf next
cf list initiatives
cf list plans
cf list slices
cf list tasks
cf list items
cf project get
  • status shows current workflow position.
  • next recommends the next action.
  • list initiatives shows architecture initiatives.
  • list plans finds slice plans and progress.
  • list slices shows slices in the active plan.
  • list tasks shows task files and completion.
  • list items shows individual tasks.
  • project get shows all project fields.

Discover options with cf --help or cf <command> --help.

Build working context

cf build
cf build --phase P4
cf build --phase P5 --slice 175
  • cf build uses the current project phase and selection.
  • --phase P4 builds context for slice design.
  • --slice 175 focuses context on that slice.

Use the resulting context with your usual coding assistant instead of launching a full SQ pipeline.

P1 Concept · P2 Architecture · P3 Slice Planning · P4 Slice Design · P5 Task Breakdown · P6 Implementation · P7 Integration.

Update project state

cf get
cf set phase 4
cf set slice 175
cf config get
cf config set default_project my-project
  • get shows project fields.
  • set phase changes phase and matching instruction.
  • set slice selects a slice and can resolve its files.
  • config get lists configuration values.
  • config set saves a configuration preference.

Check cf status and cf get first when unsure what is selected.

Check consistency carefully

cf check
cf check --slice 175
cf check --fix
  • check reports inconsistencies across project documents.
  • --slice 175 narrows checks to one slice.
  • --fix writes corrections; it is not read-only.

In registered worktrees, fixes for documents owned by another checkout may be committed there. Inspect findings and worktree scope before allowing fixes.

Choose the right tool

  • CF: inspect or update project state; browse artifacts; assemble context.
  • SQ review: get a structured second opinion on a design, tasks, or code.
  • SQ pipeline: run a repeatable chain of AI work and review steps.

Working with Squadron

Squadron (sq) runs reviews and multi-step AI pipelines on top of CF. Give it a slice number and it finds the slice’s design, tasks, and phase through CF.

sq review slice 175 -v
sq run P4 175 --dry-run

See the Squadron README to install it and for its own quick reference.
